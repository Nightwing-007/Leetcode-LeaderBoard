# Sri Eshwar College of Engineering - Coding & PGP Leaderboard Portal

Full-stack college leaderboard platform with **React + Vite** frontend (preserving SECE Navy `#003366` & Gold `#FFB800` theme), **Spring Boot 3.3.x** REST backend, and **PostgreSQL** database.

## 🚀 Running the Application

### 1. PostgreSQL Database Setup
1. Create a database in PostgreSQL:
```sql
CREATE DATABASE sece_leaderboard;
```
2. The schema will be auto-generated by Hibernate / `schema.sql` upon running the backend.

### 2. Run the Spring Boot Backend
1. Open terminal in `backend/`:
```bash
cd backend
```
2. Configure credentials in `application.yml` or pass via environment variables (`DB_USER`, `DB_PASSWORD`, `DB_NAME`).
3. Run with Maven or your IDE (IntelliJ / WebStorm with JDK 17/21/25):
```bash
mvn spring-boot:run
```
The REST API will start at `http://localhost:8080`.

### 3. Run the React Frontend
1. Open terminal in `frontend/`:
```bash
cd frontend
npm install
npm run dev
```
The web application will open at `http://localhost:3000` (or `http://localhost:5173`).

## 🏆 Key Features

- **Multi-Tab Leaderboard**:
  - 🏆 **LeetCode Global**: Global ranking, contest ratings, contests attended, problems solved (Easy/Med/Hard).
  - ⚡ **PGP / SkillRack**: 1,260+ student rankings with total points, programs solved, DC, DT, and code tests.
  - 🌟 **Composite Rank**: Integrated college ranking score.
- **Top 3 Hall of Fame Podium**: 3D glassmorphic gold/silver/bronze cards with celebratory confetti.
- **Smart TV Kiosk Broadcast Mode**: Auto-rotating slideshow display designed for laboratory monitors.
- **Excel Ingestion (Apache POI)**: Uploads `Batch (2024-2028) PGP Report.xlsx` and synchronizes all records in PostgreSQL.
- **Admin PIN Protection**: Passkey (`sece2026`) for report uploads and student record modifications.
